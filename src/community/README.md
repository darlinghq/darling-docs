# Community

The strength of the Darling ecosystem lies in its contributors and supporters. Beyond the core runtime and official repositories, developers from all over the world maintain package repositories, write guides, and help expand macOS compatibility on Linux.

## Getting Involved

There are many ways to participate and contribute to the community:

* **Maintain Packages:** Package software and dependencies for various Linux distributions to make installing Darling and its ecosystem seamless.
* **Share Knowledge:** Write tutorials, document test results, or help other users in our discussion channels.

## Community Resources & Guidelines

While we encourage open exploration and third-party development, please keep the following in mind:

> <div class="warning">
>
> **Note:** Unless explicitly stated, community projects are independently maintained by their respective authors and are not officially vetted or endorsed by the core Darling team.
>
> </div>

* **Support:** For help with a specific community project, please open an issue directly in that project's repository.
* **Submissions:** Want to add a package to our list? Feel free to open a Pull Request in the [`darling-docs`](https://github.com/darlinghq/darling-docs) repository.
